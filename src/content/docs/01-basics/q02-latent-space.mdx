## 一句話

[Q1：擴散模型](../01-basics/q01-diffusion/) 說模型從雜訊中雕刻出畫面——但不在像素上雕，VAE 先把畫面壓成只保留結構的語意草圖，雕刻在這張草圖上進行。

![Stable Diffusion 架構圖：Pixel Space → VAE Encoder → Latent Space → Denoising → VAE Decoder → Pixel Space](latent-space.png)

▲ 完整 pipeline：像素經過 Encoder 壓縮進潛在空間，模型在潛在空間中去噪雕刻，Decoder 再把雕好的語意草圖還原成最終畫面。

## 為什麼不能在像素上直接雕刻？

兩個理由。

第一，算不動。512×512 的畫面有 26 萬個像素。一刀處理 26 萬個數字，幾十刀下來消費級 GPU 根本跑不動。

第二，像素太吵。同一座雕像，光線角度一變，每一粒砂子的反光都變了——兩張照片在像素層面截然不同。但雕像的「形」——肩膀弧度、下巴陰影——完全沒變。模型要學的是不變的結構，不是會變的砂粒反光。在像素上直接雕刻，模型會被海量表面雜訊淹沒，學不到真正的形。

兩個問題指向同一個解法：換到一個只保留結構、丟掉表面雜訊的空間工作。

## 潛在空間：只保留結構的語意草圖

VAE（Variational Autoencoder，變分自編碼器）把 512×512 像素轉成一張 64×64 的語意網格。這張網格存的不是顏色——是結構：「這裡是臉的輪廓」「那裡是光影的邊界」。

這不是把圖縮小。是把圖轉成另一種語言：從「這個點什麼顏色」變成「這裡有什麼結構」。[LDM 論文（Rombach et al., CVPR 2022 §3.1）](https://arxiv.org/abs/2112.10752) 稱這個過程為感知壓縮（perceptual compression）——把肉眼不可察的高頻細節抽象掉，只保留感知上重要的結構。降採樣倍率 f=8，運算量降 64 倍。

[Q3：圖像區塊化](../01-basics/q03-patchify/) 接棒下一步：這張 64×64 語意網格會被切成 patch、變成 token，送進 DiT 做去噪雕刻。

## VAE：像素 ⇄ 語意的雙向轉換

Encoder 把像素壓成語意草圖。Decoder 把雕好的草圖還原成像素。

```
512×512 像素（26 萬個數字）
       ↓  VAE Encoder（感知壓縮 64 倍）
64×64 語意草圖（4 千個數字）← 去噪雕刻在這裡
       ↓  VAE Decoder（還原）
512×512 像素（最終畫面）
```

:::tip[🎬 導演要點]

Prompt 指揮的是語意草圖，不是像素。空間關係直接命中結構——「站在左側，光從右來」比「紅衣服」更優先被模型理解。

寫 prompt 先講空間佈局，再補顏色材質。

:::
