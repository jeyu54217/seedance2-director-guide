## 一句話

模型不在像素上雕刻——先把畫面壓成語意網格，雕完再放大回來。

## 為什麼需要潛在空間？

Q1 說模型一刀一刀鑿掉雜訊。但 512×512 的畫面有 26 萬像素。一刀處理 26 萬個數字，20 刀就 500 萬次。家用 GPU 跑不動。

解法：**不在像素上動刀。** 先用 **VAE（Variational Autoencoder）** 把畫面壓縮 64 倍，在壓縮後的網格上去噪，最後再放大回像素。這張壓縮網格就是**潛在空間（Latent Space）**。

## VAE：像素 ⇄ 語意的雙向轉換器

**Encoder** 把 512×512 像素壓成 64×64 網格——存的不是顏色，是語意（人臉輪廓、光影方向、物體邊界）。**Decoder** 把去噪完的 64×64 網格放大回 512×512 像素。

```
512×512 像素（26 萬個數字）
       ↓  VAE Encoder 壓縮 64 倍
64×64 語意網格（4 千個數字）← 去噪在這裡
       ↓  VAE Decoder 還原
512×512 像素（最終畫面）
```

## 64 倍：消費級 GPU 跑得動的原因

512×512×3 → 64×64×4，運算量降 64 倍。Stable Diffusion 能在消費級 GPU 上跑，就是這一步。

:::tip[🎬 導演要點]
Prompt 指揮的是**語意網格**，不是像素。

「站在左側，光從右來」→ 空間關係直接命中結構。

「紅衣服」→ 顏色是後段細節，不是第一優先。

**Prompt 先講空間，再補顏色材質。**
:::
