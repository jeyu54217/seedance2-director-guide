## 為什麼按這個順序讀？

論文不是按發表年份排的——是按**架構理解的依賴關係**：

- **Layer 1–2（廣度）**：先知道整個領域長什麼樣子、你手上的工具能做什麼
- **Layer 3（深度）**：再往下挖架構——DiT、Flow Matching、MMDiT——這是所有操控技術和問題診斷的基礎
- **Layer 4–5（應用）**：有架構基礎後，操控技術（ControlNet、IP-Adapter）和去幻覺技術（CFG、RescaleCFG）的原理才是可理解的，不是死背參數
- **Layer 6（前沿）**：最後看領域正在往哪裡走——稀疏注意力、物理評測、高效推理

每層論文右欄標注了對應的 Q 編號，方便讀完論文回頭查 guide 中的應用解釋。

:::tip[🎬 導演要點]

**不需要從頭讀到尾。** 按你的目的選入口：

- 想理解為什麼參數這樣設 → Layer 3（DiT + Flow Matching），再讀 Layer 5（CFG + RescaleCFG）
- 想解決具體問題 → Layer 4（操控技術），對照 [Part 3：問題診斷](../03-diagnosis/q27-lighting-face/) 找對應 Q
- 想知道 Seedance 能做什麼、不能做什麼 → Layer 2（Model Card） + Layer 5（AV-Phys Bench 量化限制）
- 想看領域趨勢 → Layer 1（Survey） + Layer 6（前沿）

每層重點章節已標注——不需要讀全文。§3–4 通常是架構和方法，跳過 §1–2（引言/相關工作）和 §5+（實驗/附錄）可省 50% 閱讀時間。

:::

:::note[📖 關於 AV-Phys Bench]
AV-Phys Bench 放在 Layer 5（去幻覺）而非 Layer 6（前沿），因為它在 [Q12](../02-seedance/q12-training/)、[Q20](../03-diagnosis/q20-limb-melting/)、[Q25](../03-diagnosis/q25-physics-failure/) 中被大量引用作為物理理解的量化基準——種子舞 2.0 總通過率 66.0%，事件轉換場景僅 53.5%。理解這個數字比知道它是最新 benchmark 更有實戰價值。
:::
