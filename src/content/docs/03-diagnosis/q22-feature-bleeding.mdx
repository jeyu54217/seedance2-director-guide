## 🔍 根因

Dynamic Weight Masking（Q9）的遮罩 A=Softmax(QKᵀ/√dk+M) 依賴模型特徵解耦能力。角色視覺特徵太接近（同色系、同髮色）→ 解耦失敗。MindStudio 測試：Identity Slot 上限 ~2 角色。

## 🛠️ 解法

- **ComfyUI**：Regional Prompting + SAM 預分割，每個 IP-Adapter 只綁定對應 mask 區域
- **Seedance**：角色色系差異最大化（紅 vs 藍 >> 紅 vs 橘）。純色背景特寫。**≤2 角色**
