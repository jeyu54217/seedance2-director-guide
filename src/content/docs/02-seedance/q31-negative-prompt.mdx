## 一句話

Seedance 2.0 沒有負面提示——文字編碼器聽不懂「不」、CFG 沒有負面通道、Attention 沒有排除語法，否定句不只無效，還會反效果。

## 為什麼其他模型可以，Seedance 不行？

[Q5：CFG](../01-basics/q05-cfg/) 的機制：每一步去噪模型跑兩次預測，一次有 prompt、一次沒有，CFG 在兩者之間線性外推。Stable Diffusion 和 Midjourney 的負面提示就是把「無 prompt」那端換成「負面 prompt」——外推方向變成偏離負面、靠近正面。**這需要架構上有兩個獨立的文字輸入點。**

Seedance 2.0 沒有第二個輸入點。[Q9：多模態融合](../02-seedance/q09-multimodal-fusion/) 的 Joint Self-Attention 把文字、圖片、影片全塞進同一個注意力空間——沒有預留獨立的負面提示通道。CFG 只有兩種模式：有 prompt 和完全空白。這不是功能缺漏，是 MM-DiT 架構的設計取捨——選了模態間深度融合，代價是無法簡單插入第二組文字條件。

## 那在 prompt 裡寫「不要」總可以吧？

不行。而且有三層原因，從文字編碼一路到 Attention 全卡住。

### 第一層：文字編碼器聽不懂否定

CLIP 等文字編碼器對否定詞近乎失明（Alhamoud et al., CVPR 2025）。測試中「a scientist not wearing glasses」和「a scientist wearing glasses」的語意向量幾乎完全重疊。否定詞在 embedding space 中只是一個極微弱的偏移，被內容詞（scientist、glasses）完全壓過去。你寫「不要多手多腳」——模型讀到的關鍵詞是「多手多腳」，否定詞沒有改變任何事。

### 第二層：CFG 外推方向正好相反

CFG 的無條件分支用的是空白向量——不是「不要多手多腳」的 embedding。模型在「有 prompt」那輪讀到「多手多腳」，在「無 prompt」那輪什麼都沒看到。外推方向是遠離空白、靠近「多手多腳」——**你等於在幫模型放大你不想看到的東西。**

### 第三層：Self-Attention 沒有排除語法

[Q4：注意力機制](../01-basics/q04-attention/) 的 Query/Key/Value 共用同一個權重矩陣——所有 token 平等對待。架構上沒有地方可以標記「這是排除符號，後面的內容詞要反向加權」。Attention 只知道 token 之間要互相對看，不知道什麼叫「不要」。

## 沒有負面提示，怎麼約束？

全部正著說。三個方法。

正向改寫。「不要晃」→「static shot, locked-off camera」。「不要多手多腳」→「two arms, two legs, anatomically correct proportions」。「畫面不要有雜物」→「clean, minimal background」。原則只有一條：描述你要的畫面，不要描述你不要的。

用 @ 標籤鎖定視覺。文字編碼器聽不懂否定，但 [Q11：@ 標籤](../02-seedance/q11-at-tags/) 的 embedding slot 繞過文字編碼器，直接把視覺特徵灌進 Cross-Attention。不要寫「不要變臉」——上傳參考圖到 `@image1`。不要寫「不要亂動」——上傳動作參考到 `@video1`。

把約束包裝成畫面屬性。注意某些 prompt 範例中的 "no extra text, no logo distortion"——這些不是 CFG 負面提示，是正向視覺類別標籤。模型在訓練中見過這些片語對應的畫面（乾淨、無文字），效果來自語意關聯而非反向推力。對簡單約束勉強有效，複雜否定（不要特定動作、不要特定物體）完全沒用。

:::tip[🎬 導演要點]

Seedance 2.0 的 prompt 是內容描述系統，不是指令系統。你寫的每個字都在告訴模型「畫面裡有什麼」——包括你不想看到的東西。

永遠正著寫。把每個「不要」改寫成「要什麼」。這不是 prompt 技巧，是架構決定的唯一可行路徑。靠 @ 標籤做視覺約束，靠 prompt 做正向描述——不要試圖讓模型讀懂否定句，它真的讀不懂。

:::
