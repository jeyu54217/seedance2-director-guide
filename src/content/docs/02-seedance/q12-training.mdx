## 一句話

運鏡能力和物理外觀來自三階段訓練（預訓練→SFT→RLHF/DPO），但所有模型在真正理解物理因果上仍然失敗——最佳模型在事件轉換場景的物理通過率只有 53.5%。

## WHY：訓練決定上限

影片生成模型沒有內建物理引擎或鏡頭規劃器。它會的一切都是從訓練資料中學到的統計規律。[Q10：為什麼可以一次生成帶聲音的影片？——雙分支架構（Dual-Branch DiT）](../q10-dual-branch/) 說明的雙分支 DiT 架構決定計算結構，但真正決定模型能力的，是訓練方法和訓練資料。

## 第一階段：大規模預訓練——學統計規律

預訓練任務：給模型看數億支影片，每支加雜訊再學著去掉（去噪自監督學習）。過程中模型自己發現規律：蘋果往下掉、水往低處流、鏡頭推近時主體變大。不是理解 F=ma，是看過太多次「往下掉」，統計上「往上飄」的機率趨近於零。

各家做法大同小異，典型流程：

1. **多階段解析度排程**：從低解析度逐步升到高解析度。先用純圖片建立文字-視覺基礎對齊（純圖片效果優於混合影片），再逐步加入影片學習時間連續性。圖片+影片混合訓練是關鍵——純影片無法建立文字語義對齊，純圖片學不到幀間關係
2. **資料篩選 pipeline**：過濾時長過短過長、解析度太低、長寬比極端 → 畫質模型評分去低分 → 運動向量分析去不穩定運鏡 → CLIP 聚類確保多樣性

預訓練產出「能看」的畫面，但美學粗糙、運鏡呆板、動作僵硬。

## 第二階段：SFT（Supervised Fine-Tuning，監督微濾）——從能看到好看

收集高品質影片（人工篩選、專業審美標準），繼續用去噪任務微調。目標是學習高品質構圖、色彩、光線、運鏡。

以 Kling 團隊的公開做法為例（[VideoReward, §5.2](https://arxiv.org/abs/2501.13918)）：只用偏好標註中「被選擇」的高品質影片做 SFT，捨棄對照組。

**副作用**：過度 SFT 會破壞動作品質和 prompt 跟隨能力。高美學 SFT 資料偏向靜態構圖，模型過度適應後畫面變漂亮但動作幅度縮小、對文字指令反應變弱。

## 第三階段：RLHF / DPO——讓人類偏好指導模型

SFT 改善美學，但動作和物理一致性仍不足。第三階段的核心是 **RLHF**（Reinforcement Learning from Human Feedback，人類回饋強化學習）和 **DPO**（Direct Preference Optimization，直接偏好優化）——直接告訴模型「人類覺得什麼好」，朝那個方向調整。

以 Kling 團隊的 VideoReward（[NeurIPS 2025](https://arxiv.org/abs/2501.13918)）——目前最公開的影片 RLHF 論文——為例：

**偏好資料**：16,000 個 prompt × 12 個模型生成 = 10.8 萬支影片，組合成 18.2 萬組對比。人類標註者在三個維度各自判 A 贏、B 贏或平手。

**三個評分維度**：

- **Visual Quality（畫面品質）**：有無生物或邏輯錯誤（如多餘手指、扭曲的臉）、清晰度
- **Motion Quality（動作品質）**：幀間連續穩定、動作自然度（服裝隨動作飄動、表情合理變化）、無鬼影閃爍、動作幅度是否足夠——幾手靜止的影片在這項拿低分
- **Text Alignment（文字匹配）**：主體、動作、場景、風格、運鏡五個面向是否與 prompt 一致

**裁判模型設計**：用視覺語言模型（Qwen2-VL-2B）當裁判，以每秒 2 幀均勻取樣影片（非固定張數，確保長短片公平），解析度約 448×448。在影片 token 和文字 token 間插入 `[VQ]` 和 `[MQ]` 特殊 token——它們只看影片不碰文字，防止 prompt 內容干擾畫面/動作的評分；`[TA]` token 則同時看影片和文字。

**三種對齊方法**，可組合使用：

1. **Flow-DPO**：不先訓練裁判，直接用偏好對（A > B）調整模型去噪方向，讓輸出傾向贏的那邊。用極小 learning rate 加 LoRA 防止品質崩潰
2. **Flow-RWR**：高分影片訓練權重大，低分權重小
3. **Flow-NRG**：推論時介入，去噪過程中往高獎勵方向微調，不重新訓練

比傳統 RLHF（ChatGPT 用的 PPO）更簡單——不需同時維護裁判模型，訓練更穩定。

## 物理理解的真相：所有模型都還差很遠

[AV-Phys Bench](https://arxiv.org/abs/2605.07061)（Tian et al., §4）是目前唯一同時測試視覺物理、音訊物理、跨模態物理一致性的 benchmark。7 個模型，三種場景類別：

| 場景類別 | 說明 | Seedance 2.0 | Kling 3.0 |
|---------|------|-------------|-----------|
| Steady State | 場景不變，單一事件 | 72.0% | 49.2% |
| Event Transition | A 觸發 B（敲鐘→迴盪） | 53.5% | 18.6% |
| Environment Transition | 場景改變（室內→室外） | 71.9% | 28.1% |
| **物理常識總通過率** | | **66.0%** | **34.3%** |

三個關鍵事實：

**語義與物理的落差**：Seedance 2.0 語義遵循 90.3%，物理常識 66.0%。模型知道應該生成什麼，但不知道生成的東西物理上對不對。

**事件轉換是所有人的死穴**：一到事件轉換場景（事件 A 觸發事件 B），物理分數全部大跌——Seedance 跌 26%，Kling 跌 62%。模型不善於處理因果鏈。

**不會拒絕不合理指令**：故意給違反物理的 prompt（「敲鐘但沒有聲音」），Seedance 2.0 的表現也大跌 45–69%。模型不會說不行，只會硬做然後產出錯的結果。

核心結論：Physics Reward 只讓模型學會輸出「看起來符合物理的畫面」。和「理解物理」是兩回事——模型不知道 F=ma，它只知道這種畫面排列在訓練資料中出現的機率很高。

:::tip[🎬 導演要點]

簡單物理（走路、放杯子）可信任。複雜場景（打鬥、液體、多物體互動）用 ControlNet 注入深度或姿態先驗輔助約束。

事件轉換是所有模型的弱項。設計 prompt 時避免因果鏈，拆成單一事件各自生成。

模型不會拒絕不合裡指令——prompt 中的物理合理性由導演把關。

:::
