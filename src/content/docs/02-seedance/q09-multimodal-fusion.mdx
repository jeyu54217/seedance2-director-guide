## 一句話

各模態各自編碼成 token、串成同一條序列，Joint Self-Attention 讓所有 token 在每一步去噪中跨模態互相對看、持續對齊。

## 如果不融合，會怎樣？

你同時給了文字 prompt 和 `@image1` 參考圖（[Q11：@ 標籤](../02-seedance/q11-at-tags/)）。文字說「金髮」，圖片是紅髮。如果兩條輸入分開處理、各自算完再硬接——文字 token 和圖片 token 從未在同一個計算空間中對話過。模型被迫在兩個互不相通的資訊源之間妥協，結果角色長相一部分聽 prompt、一部分聽參考圖——誰都不完整。

這不是多給素材就會變好。**多模態輸入真正的難題不是編碼——是對齊。** 不同模態的 token 必須在同一個計算空間中互相看見、互相修正，融合才有意義。

## 三步：從各自編碼到跨模態對話

**第一步：全部變成 token。** 不管來源是什麼，編碼器輸出的都是同一種東西——token 序列。文字走 Text Encoder（CLIP / T5-XXL）產出語意 token；圖片走 VAE Encoder 壓 latent、切 patch，每個 patch 附上 2D 空間位置變成視覺 token；影片多一條時間軸——3D causal VAE 同時壓縮空間和時間，產出附 3D 位置（空間+時間）的時空 token。概念源於 Sora（OpenAI, 2024）的 spacetime patches，CogVideoX（Yang et al., 2024）將其與 DiT 架構結合。

**第二步：串聯，並標記來源。** 所有 token 串成一條：`[text | image | video | noise]`。但單純串聯不夠——Transformer 需要知道誰來自哪裡。解法：疊兩層位置資訊。第一層標 token 在自己模態內的空間或時間座標（[Q3：圖像區塊化](../01-basics/q03-patchify/) 的 patch 網格、[Q6：時間步調節](../01-basics/q06-timestep/) 的位置編碼）；第二層是模態標記（Modality-Specific Position Embedding），告訴模型「這一區是文字」「這一區是圖片」。模型同時知道 token 的空間位置和來源模態。

**第三步：Joint Self-Attention——跨模態對話。** 串聯後的序列送進 DiT，[Q4：注意力機制](../01-basics/q04-attention/) 的 Self-Attention 在所有 token 上運算，不管來源。文字可以看向圖片、noise 可以看向影片。數學上就是 `Attention(Q,K,V) = softmax(QKᵀ/√d) × V`，只是輸入序列包含了多模態。背後的架構是 MM-DiT（SD3, Esser et al., 2024）：各模態有獨立的權重和 LayerNorm，但在 Self-Attention 層共用 QKV 計算——各自正規化、共同注意。

**這就是跨模態一致性的來源。** 參考圖的 visual token 和 noise token 從 step 999 到 step 0，每一步、每一層都在一起計算。noise token 持續看向參考圖 token，每一步都在調整自己的特徵向量跟參考圖對齊。角色跨多秒不變臉——不是生成完修圖，是每一步都在對齊。

## 對導演來說，這代表什麼？

文字和參考圖有協同效果。Joint Attention 讓文字 token 和視覺 token 在同一層交換資訊——寫 `"@image1 的角色站在黃昏沙灘上"` 比先畫角色再加背景有效，文字語意直接疊加在視覺特徵上。

多素材隔離靠特徵距離。素材色系差異越大（紅 vs 藍 >> 紅 vs 橘），特徵向量在 Attention 空間中距離越遠，隔離越乾淨。兩個黑髮角色同時引用，特徵容易混淆——這是 Identity Drift 的機制根源（見 [Q23：身分漂移](../../03-diagnosis/q23-identity-drift/)）。

Prompt 具體程度決定融合強度：「午後陽光從窗戶斜射進來，地上長方形光斑」>「溫暖的房間」。

:::tip[🎬 導演要點]

Joint Attention 是 Seedance 跨模態一致性的根基——參考圖角色不變臉不是靠後製，是靠每一步持續對齊。

素材上限來自注意力資源分配，不是硬體限制。兩個角色是甜蜜點，三個以上 Identity 開始漂移——每個新增角色分走一部分 Attention 權重（見 [Q28：多角色混淆](../../03-diagnosis/q28-feature-bleeding/)）。

雜亂背景會被當成 identity 特徵一起編碼——參考圖請用純色背景正面特寫。

:::
